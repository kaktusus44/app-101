# App 101

Web-приложение, функционально воспроизводящее ключевые пользовательские сценарии приложения 101.

## Цель

Изучить доступное приложение 101 по экранам и пользовательским действиям, сформировать требования и создать MVP с основными ролями и сквозными сценариями.

Мы воспроизводим наблюдаемое поведение продукта, а не пытаемся копировать неизвестную внутреннюю реализацию оригинала.

## Технологии

- Frontend: React, TypeScript, Vite, React Router, TanStack Query.
- Backend: Go, модульный монолит, REST API, OpenAPI.
- Database: PostgreSQL.
- Development environment: Docker Compose.
- Object storage и фоновые задачи добавляются только при подтверждённой необходимости.

## Как собираются требования

Каждый экран приложения 101 описывается по шаблону:

1. Название и скриншот.
2. Пользовательская роль.
3. Точка входа и переходы.
4. Поля, таблицы, фильтры и действия.
5. Результат каждого действия.
6. Состояния загрузки, пустого результата, ошибки и отсутствия доступа.
7. Обязательность для MVP.

Экран переводится в цепочку:

`экран → роль → сценарий → данные → API → критерии готовности`

## Первый этап

1. Составить карту экранов и ролей.
2. Выбрать главный сквозной пользовательский сценарий.
3. Описать сущности и состояния этого сценария.
4. Согласовать API и макеты.
5. Реализовать вертикальный срез: интерфейс, API, данные и тест.
