# 199

Веб-приложение для управления проектами, финансами и командой.

## Цель

Создать приложение 199 с основными ролями и сквозными рабочими сценариями.

Мы воспроизводим наблюдаемое поведение продукта, а не пытаемся копировать неизвестную внутреннюю реализацию оригинала.

## Технологии

- Frontend: React, TypeScript, Vite, React Router, TanStack Query.
- Backend: Go, модульный монолит, REST API, OpenAPI.
- Database: PostgreSQL.
- Development environment: Docker Compose.
- Object storage и фоновые задачи добавляются только при подтверждённой необходимости.

## Как собираются требования

Каждый экран приложения 199 описывается по шаблону:

1. Название и скриншот.
2. Пользовательская роль.
3. Точка входа и переходы.
4. Поля, таблицы, фильтры и действия.
5. Результат каждого действия.
6. Состояния загрузки, пустого результата, ошибки и отсутствия доступа.
7. Обязательность для MVP.

Экран переводится в цепочку:

`экран → роль → сценарий → данные → API → критерии готовности`

## Первый этап

1. Составить карту экранов и ролей.
2. Выбрать главный сквозной пользовательский сценарий.
3. Описать сущности и состояния этого сценария.
4. Согласовать API и макеты.
5. Реализовать вертикальный срез: интерфейс, API, данные и тест.

Архитектурный черновик находится в [docs/architecture.md](docs/architecture.md).

Скриншоты и описания страниц складываются в [docs/screens](docs/screens/README.md).

## Текущий MVP

Первый frontend-срез уже содержит:

- серверную авторизацию, HttpOnly-сессии и защищённые маршруты;
- профиль клиента с выходом из аккаунта;
- главную панель и меню добавления события;
- пустой список проектов;
- форму нового проекта.
- прайс-листы, категории и позиции с учётом ролей.

Запуск:

```bash
npm install
npm run dev
```

Полный запуск в Docker:

```bash
docker compose up --build
```

Приложение откроется на `http://localhost:8088`. PostgreSQL хранит данные в Docker volume.
При первом запуске API создаёт две демо-учётные записи с паролем `demo`:

- `demo@app199.ru` — организация, права редактирования;
- `client@app199.ru` — клиент, только просмотр.

Для разработки frontend отдельно выполните `npm run dev`; Vite проксирует `/api` на Go API
на порту 8080. Авторизация, роли, профиль, приглашения, проекты, прайс-листы, статьи расходов,
финансовые события и настройки документов хранятся на сервере в PostgreSQL. Бизнес-данные
не сохраняются в локальном хранилище браузера.

Рабочий план находится в [docs/roadmap.md](docs/roadmap.md).
