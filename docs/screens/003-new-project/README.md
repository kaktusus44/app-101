# Новый проект

## Скриншоты

- `screen-default.jpg` — пустая форма создания проекта.

## Наблюдаемое назначение

Создание проекта и привязка его к заказчику.

## Как пользователь сюда попадает

Нажимает плавающую кнопку создания на странице «Проекты».

## Поля

### Информация о проекте

- Название.
- Заказчик — выбирается из отдельного интерфейса.
- Дата завершения — выбирается через отдельный интерфейс или календарь.
- Площадь в м².
- Адрес; подсказка сообщает, что адрес используется во всех документах и должен совпадать с договором.

### Дополнительно

- Ссылка на фотоальбом.
- Действие «Вставить», вероятно вставляет значение из буфера обмена.
- Справочная ссылка о создании общего альбома и копировании ссылки.

## Действия

- Возврат без сохранения.
- Выбор заказчика.
- Выбор даты завершения.
- Вставка ссылки на фотоальбом.
- Сохранение проекта.

## Предварительная модель данных

```text
Project
- id
- company_id
- name
- customer_id
- completion_date
- area_m2
- address
- photo_album_url
- created_at
- updated_at
```

Состав полей предварительный и должен быть подтверждён дальнейшими экранами.
