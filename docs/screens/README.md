# Экраны приложения 199

Здесь хранятся скриншоты оригинального приложения и описания наблюдаемого поведения страниц.

## Структура

Для каждого экрана создаётся отдельная папка:

```text
docs/screens/
  001-login/
    screen.png
    README.md
  002-dashboard/
    screen-default.png
    screen-empty.png
    README.md
```

## Именование

- Папка: порядковый номер и короткое имя страницы, например `003-user-list`.
- Основной снимок: `screen.png` или `screen-default.png`.
- Состояния: `screen-empty.png`, `screen-error.png`, `screen-modal.png`.
- Описание страницы: `README.md` по шаблону [page-template.md](../page-template.md).

Не добавляйте реальные пароли, токены, персональные данные и иную конфиденциальную информацию. Перед сохранением скриншота такие данные нужно скрыть.

Пример оформления находится в папке [examples/001-example-page](examples/001-example-page/README.md).
