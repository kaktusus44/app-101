# Проекты

## Скриншоты

- `screen-empty.jpg` — список проектов в пустом состоянии.

## Наблюдаемое назначение

Поиск, просмотр и создание проектов компании.

## Как пользователь сюда попадает

Предположительно нажимает карточку «Проекты» на главной панели.

## Видимые элементы

- Возврат на предыдущий экран.
- Заголовок «Проекты».
- Иконка архива или корзины — точное назначение нужно проверить.
- Иконка справки.
- Поиск.
- Пустое состояние: «Нет доступных для выбора проектов. Необходимо их добавить».
- Плавающая кнопка создания проекта.

## Наблюдаемый переход

- Нажатие плавающей кнопки открывает страницу «Новый проект».

## Состояния

- Подтверждено пустое состояние.
- Состояние списка, результаты поиска, загрузка и ошибки пока не показаны.

## Открытые вопросы

- Проекты принадлежат компании, пользователю или обоим?
- Что означает «доступных для выбора»: существует ли назначение пользователя на проект?
- Какие данные отображаются в строке или карточке проекта?
- Что делает верхняя иконка: архив, удалённые проекты или другой раздел?
- Есть ли статусы проектов, сортировка, фильтры и пагинация?
