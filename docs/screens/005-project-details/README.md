# Карточка проекта

## Скриншоты

- `screen-default.jpg` — основные данные, финансовая сводка и начало меню.
- `screen-sections.jpg` — полный набор разделов проекта.

## Данные

- название и короткое название проекта;
- заказчик, дата завершения, площадь и адрес;
- баланс, поступления и расходы.

## Разделы

- события;
- статьи расходов;
- участники;
- общий фотоальбом;
- документы;
- прайс-лист;
- получатели агентского вознаграждения;
- партнёры;
- руководитель проекта.

Рекламная информация о подписке PRO намеренно исключена из продукта.
