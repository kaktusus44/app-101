# Прайс-листы

## Скриншоты

- `screen-list.jpg` — список прайс-листов.
- `screen-list-menu.jpg` — меню действий с прайс-листом.
- `screen-details.jpg` и `screen-details-full.jpg` — категории, шаблоны и позиции.
- `screen-new-category.jpg` — создание категории.
- `screen-new-item.jpg` — создание позиции.
- `screen-units.jpg` — выбор единицы измерения.
- `screen-details-actions.jpg` — изменение прайс-листа и экспорт в PDF.
- `screen-pdf-audience.jpg` — варианты PDF для подрядчика и заказчика.
- `screen-entity-actions.jpg` — изменение, дублирование, перемещение и удаление шаблона/позиции.

## Наблюдаемый сценарий

1. Пользователь открывает «Прайс-листы» с главной панели.
2. В списке видит название и количество категорий, шаблонов и позиций.
3. Организация может добавить, переименовать, дублировать, экспортировать или удалить прайс-лист.
4. Внутри прайс-листа позиции группируются категориями и могут использовать шаблоны.
5. Для позиции задаются название, единица измерения, себестоимость и цена.
6. Прибыль и маржинальность вычисляются из себестоимости и цены.
7. PDF для подрядчика содержит только себестоимость, PDF для заказчика — только цену.
8. Шаблоны и позиции можно изменять, дублировать, перемещать и удалять.

## Ролевая модель MVP

- Организация: просмотр и все действия изменения.
- Клиент: только просмотр списка и содержимого прайс-листа.

## Модель данных

```text
PriceList: id, company_id, name
PriceCategory: id, price_list_id, parent_id?, name
PriceTemplate: id, price_list_id, category_id?, name
PriceItem: id, price_list_id, category_id?, name, unit, cost, price
```

Экспортированный XLSX подтверждает колонки: категория, позиция, единица измерения,
себестоимость и цена. Список допустимых единиц измерения хранится отдельно.

## Следующий backend-срез

- CRUD прайс-листа, категории и позиции.
- Проверка роли на каждом изменяющем endpoint.
- Вычисление прибыли и маржинальности на чтении.
- Экспорт XLSX/PDF после появления серверного хранилища.
