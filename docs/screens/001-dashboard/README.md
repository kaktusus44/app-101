# Главная панель

## Скриншоты

- `screen-default.jpg` — основное состояние.
- `screen-add-event.jpg` — открыто нижнее меню «Добавить событие».

## Наблюдаемое назначение

Стартовый экран компании. Показывает сводные показатели и даёт переходы в основные разделы приложения.

## Видимые данные и переходы

- Выбранная компания: «КАРГОПЛАСТ»; рядом элемент выбора или перехода.
- Время последнего обновления данных.
- Настройки — иконка шестерёнки.
- Проекты — количество и прибыль за период «4 недели».
- Контрагенты — подотчётный баланс и доход за «4 недели».
- История событий — количество событий.
- Прайс-листы.
- Фонд компании — текущий баланс.
- Аналитика.
- Нижняя навигация оригинала: «Полезное», «Помощь», «Чат», «Руководство».
- Плавающая кнопка `+` открывает меню добавления события.

## Меню «Добавить событие»

Доступные типы:

- поступление;
- отчёт;
- перевод;
- смета;
- отдельная кнопка QR рядом с отчётом.

Фон страницы затемняется, меню открывается снизу.

## Предварительные сущности

- Компания.
- Проект.
- Контрагент.
- Событие.
- Прайс-лист.
- Фонд компании.

## Отличия нашей реализации

- Чаты, «Чат», «Помощь» и «Руководство» исключены из продукта как ненужные.
- Нижняя навигация целиком исключена из текущей версии продукта.
